Справка и помощь

        
      

      
Коротко и по делу: как всё устроено и что нажимать. Раскрывай нужный раздел. Не понятно что-то на экране — наведи курсор на кнопку или поле, появится подсказка.


      

        С чего начать (за 4 шага)
        

          
    
            
  1. Заполни профиль — вкладка «Онбординг». Чем подробнее, тем точнее подбор и письма.
    2. 
            
  2. Подключи поиск — «Источники» → выбери площадку → «Синхронизировать». Появятся вакансии.
    3. 
            
  3. Выбери вакансию — на «Вакансиях» кликни строку, справа откроются детали и AI-панели.
    4. 
            
  4. Проверь отклик — кнопка «План отклика HH» (безопасно, без отправки), затем «Откликнуться на HH» с подтверждением.
    5. 
          

          
Проще всего пройти это через Мастер первого отклика — кнопка вверху или в левом меню.

        

      


      

        Подключение hh.ru (токен)
        

          
Для реальных откликов нужен доступ к твоему аккаунту hh.ru. Токен вставляется в «Настройки» → «Ключи и токены HH».

          
    
            
  • Токен доступа живёт около 2 недель и обновляется автоматически.
    • 
            
  • Галочку «Разрешить реальные отклики» включай только когда готов отправлять отклики по-настоящему.
    • 
            
  • Все данные хранятся локально на твоём устройстве и никуда не передаются.
    • 
            
  • Совет: скрывай номер телефона от работодателя в резюме, если рассылаешь отклики.
    • 
          

        

      


      

        Какой AI выбрать
        

          
AI помогает писать сопроводительные письма, оценивать соответствие и подсказывать. Настраивается в «Настройки» → «Бэкенд AI».

          
    
            
  • Codex CLI (подписка ChatGPT) — без ключа API. Один раз в терминале: codex login. Рекомендуется, если есть подписка ChatGPT.
    • 
            
  • Ключ API (OpenRouter) — платишь за токены по факту; вставь ключ и модель.
    • 
            
  • OpenCode / Codex app-server — для продвинутых, локальные движки.
    • 
          

          
Можно работать и без AI: письма по шаблону доступны всегда.

        

      


      

        Поиск вакансий и язык запросов
        

          
В поиске hh.ru можно использовать операторы, чтобы отсеять лишнее:

          
    
            
  • (Python OR Django) NOT PHP NOT Java — Python или Django, но без PHP и Java.
    • 
            
  • Кавычки ищут точную фразу: "backend developer".
    • 
          

          
В приложении: фильтры по источнику, минимальному score, уровню и удалёнке; есть AI-поиск — опиши вакансию словами.

          
Подробно про язык запросов hh.ru: hh.ru/article/1175

        

      


      

        Отклики: безопасность и лимиты
        

          
    
            
  • Реальный отклик уходит только после подтверждения. Сначала всегда есть «План отклика» (проверка без отправки).
    • 
            
  • Лимит hh.ru — примерно 200 откликов в сутки. Не превышай, чтобы не попасть под ограничения.
    • 
            
  • Не вставляй ссылки в сопроводительные письма — это повышает риск теневого бана.
    • 
            
  • Кампании имеют дневной лимит и кнопку «Стоп» на случай, если что-то пошло не так.
    • 
          

        

      


      

        AI-фильтр кампаний: light и heavy
        

          
    
            
  • выкл — без AI-отсева, берём все подходящие по score.
    • 
            
  • лёгкий (light) — быстрая оценка по названию и ключевым навыкам.
    • 
            
  • строгий (heavy) — полный анализ: должность, навыки, опыт, задачи. Точнее, но медленнее и дороже.
    • 
          

          
Пропущенные вакансии сохраняются с причиной — можно разобрать позже.

        

      


      

        HH Агент: что делают операции
        

          
    
            
  • Проверка готовности — проверяет авторизацию, лимиты и окружение перед запуском.
    • 
            
  • Загрузить / Обновить резюме — «Обновить резюме» поднимает дату публикации (как кнопка «Обновить дату» на hh.ru).
    • 
            
  • Синхр. переписку — подтягивает отклики и сообщения работодателей.
    • 
            
  • Согласования — очередь действий агента: одобрить / отклонить / изменить перед выполнением.
    • 
            
  • Очистить отклики — массовая отмена откликов; Чёрный список — исключить работодателей.
    • 
          

        

      


      

        Горячие клавиши
        

          
    
            
  • / — перейти к поиску вакансий.
    • 
            
  • ? — показать или скрыть гид первого запуска.
    • 
            
  • Esc — закрыть мастер, форму или снять выделение.
    • 
            
  • Enter в чате — отправить сообщение AI-ассистенту.
    • 
          

        

      


      

        Частые вопросы
        

          
Список вакансий пустой. Зайди в «Источники» и нажми «Синхронизировать». Проверь фильтр «Мин. score».

          
Кончились подходящие вакансии. Склонируй резюме и сделай его активным — можно откликаться по второму кругу.

          
AI-письмо не генерируется. Проверь «Настройки» → «Бэкенд AI» (для Codex выполни codex login, для ключа — проверь ключ и модель).

          
Отклик не отправляется. Это нормально без подтверждения. Включи «Разрешить реальные отклики» и подтверди отправку.
