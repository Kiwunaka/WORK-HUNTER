# Requirements

- Windows 10/11 only.
- CLI and local web UI bind to 127.0.0.1 by default.
- Real apply is policy-gated, audited, and replayable.
- Codex/OpenCode auth cache files are never read, copied, logged, or exported.
- AI routes call official local runtimes or explicit API endpoints without scraping credentials.
- Candidate claims must be backed by confirmed facts before generated resume variants use them.
- Application packs must show resume variant, cover letter, short message, payload summary, risks, and preview.
- External sources must stay below real auto-apply until certified with tests, replay, redaction, and dry-run evidence.
