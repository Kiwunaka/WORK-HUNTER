# Safety Contract

- Never read Codex or OpenCode auth cache files.
- Never log tokens, cookies, auth headers, session ids, or API keys.
- Unknown forms, tests, captcha, and challenges block real apply.
- Non-certified source adapters cannot auto-apply.
- Real apply requires an enabled campaign policy, min_score pass, caps, valid session, preview, audit, replay, and kill switch off.
- The kill switch must stop planning and execution immediately.
- Dry-run and preview paths must never submit an application.
