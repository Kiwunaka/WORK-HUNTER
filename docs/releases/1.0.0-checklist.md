## Release decision

Source behavior, browser behavior, package construction, seeded wheel runtime,
UI, MCP, resource, whitespace, and tracked-secret gates are green. Publication
remains pending until an authorized networked environment completes all of the
following with exit `0`:

1. Install `.[dev,browser,ui,release]` in a clean environment and run plain
   `mypy work_hunter`.
2. Resolve the wheel and all runtime dependencies in a fresh venv, run `pip
   check`, and produce a fresh pip-audit result.
3. Build `work-hunter:1.0.0` and run its safe default container smoke.
4. Push the branch so GitHub can parse and execute the read-only CI workflow.

No final release is claimed by this checklist.
